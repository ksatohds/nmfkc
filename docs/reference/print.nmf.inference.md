# Print method for NMF inference objects

Prints a summary of any NMF inference result object (`"nmfkc.inference"`
or `"nmfae.inference"`).

## Usage

``` r
# S3 method for class 'nmf.inference'
print(x, ...)
```

## Arguments

- x:

  An object of class `"nmf.inference"`.

- ...:

  Additional arguments passed to the corresponding `print.summary.*`
  method.

## Value

Called for its side effect (printing). Returns `x` invisibly.
